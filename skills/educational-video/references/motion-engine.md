# Motion engine

The third engine. A lesson is a **pure function of time**: `window.seek(t)` paints frame `t` of an HTML page,
Playwright renders every frame in headless Chromium, ffmpeg encodes H.264. There is no timeline playing and
no animation clock, so any frame can be painted in any order, which is what makes contact sheets, single-frame
critique and exact re-renders cheap. Motion is closed-form springs (`lib/motion.js`), never easing curves.

Use it for concept explainers, kinetic typography, algorithm stepping and (later) Shorts. For derivations that
need LaTeX rigor use Manim; for UI walkthroughs use Remotion. See `engine-selection.md`.

## Set up and render

```bash
scripts/new_project.sh <base> <slug> motion      # project folder + film/ + timeline.json (or: bootstrap.sh <project> motion)
scripts/bootstrap.sh <project> motion            # npm i playwright, install Chromium, smoke-test the browser
scripts/render.sh motion <project> all low       # draft of every format  -> output/preview*.mp4
scripts/render.sh motion <project> 02 low        # one scene (film scene "s02") -> output/scene_02.mp4
scripts/render.sh motion <project> all high      # finals (60 fps, motion blur) -> output/final*.mp4
scripts/render.sh motion <project> all verify    # determinism check, every format
scripts/extract_frames.sh motion <project> all 1,8.5,15     # frames from a render, seconds on the whole film
```

`render.sh` runs `sync.mjs` first, so `film/data.js` is never stale. It is a thin wrapper: `scripts/render.mjs`
has the full set of modes, run from anywhere with `--project <dir>`:

| Command | Does |
|---|---|
| `render.mjs --project P --sheet [--fmt 9x16] [--every 1] [--phase 0.25] [--marks]` | contact sheet, one frame per second (or per mark with `--marks`), each stamped with its time. Writes `review/sheets/sheet_<fmt>.jpg` and `sheet_<fmt>_phone.jpg` (360 px tiles) |
| `--at 1.2,3.4 [--fmt 1x1]` | exact stills, `review/stills/<fmt>/t<sec>.png` |
| `--draft [--all]` | 30 fps, no blur, CRF 22 -> `renders/draft_<fmt>.mp4` |
| `[--fmt 16x9 \| --all]` | final: 60 fps, adaptive 180 degree motion blur, H.264 yuv420p CRF 16 -> `renders/<fmt>.mp4` |
| `--range 3,5` / `--scene 02` | a clip of seconds 3-5, or of one scene by storyboard id |
| `--verify [--all]` | 12 probe times painted cold and again after seeking elsewhere; all must be pixel-identical |
| `--mux [--all]` | put `audio/mix.wav` into existing renders without re-rendering |
| `--tag name`, `--fps`, `--blur 0\|1`, `--crf`, `--audio`, `--out` | output prefix, frame rate, blur, quality, audio file, output file |

Sheets and stills are painted straight from `seek(t)`, so they are frame-exact and take seconds. Look at them
(`Read` the JPG) before rendering video.

## Project layout

```
timeline.json              marks, duration, fps, formats, optional sfx: the single source of timing
grid.json                  optional: narration cue grid (see "Cue grid")
beats.json                 optional: music beat grid, only used by '@N' times and C.bt()
storyboard.json            the approved plan; its est_duration_s give nominal scene cues before narration exists
film/index.html            look tokens (:root colours, fonts) and shell
film/film.js               THE LESSON: scenes. Starts as the starter (binary search); replace it
film/core.js type.js       engine (copied from the skill; `scaffold_motion.sh <project> --update` refreshes them)
film/lib/motion.js time.js springs and the time source
film/data.js               GENERATED by sync.mjs. Never edit
cues.json                  GENERATED: sfx cues in seconds (empty until sfx are declared)
renders/ review/ output/   drafts and finals / sheets and stills / deliverables
```

## Time: seconds, marks and cues

Everything is placed in seconds. A **when** is any of:

| when | meaning |
|---|---|
| `3.25` | seconds from the start of the film |
| `'reveal'` | a mark from `timeline.json` |
| `'s03.derivative'` | a cue from the cue grid |
| `'s03.derivative+0.3'`, `'reveal-0.2'` | any of the above plus a signed offset in seconds |
| `'@16'` | beat 16 of the optional music grid (`beats.json`, or `bpm` in the timeline) |

Marks are named moments, defined once in `timeline.json` and used by name in `film.js`:

```jsonc
{ "duration": 21, "fps": 60, "formats": ["16x9", "9x16"],
  "marks": { "hook": 0, "idea": "s02.derivative", "result": "idea+1.5", "done": 21 } }
```

A mark is seconds, a cue, or another mark with an offset; loops and unknown names are errors. Tuning the lesson
means editing marks, not hunting through code. `node scripts/sync.mjs` (run by `render.sh`) resolves everything,
prints a sorted table of mark times and writes `film/data.js`. Every name is also resolved when the film starts,
so a typo fails before frame 0 with the offending name, never halfway through a render.

### Cue grid (narration plugs in here)

Cues are named seconds in `window.GRID.cues`. Without narration, `sync.mjs` derives `sNN.start` and `sNN.end`
from the storyboard's cumulative `est_duration_s`. With narration, a `grid.json` replaces the estimates:

```jsonc
{ "duration": 42.1,
  "scenes": [ { "id": "01", "start": 0, "end": 8.4 }, { "id": "02", "start": 8.4, "end": 20.3 } ],
  "cues": { "s02.derivative": 12.31, "s02.p2": 15.0, "s02.start": 8.4 } }
```

The cue names match the storyboard's `on` anchors (`s02.derivative`, `s02.derivative#2`, `s02.w12`, `s02.p2`,
`s02.start`, `s02.end`; see `storyboard-schema.md`). Write the film against cue names (`'s02.derivative'`) or marks
that point at them, and it keeps its sync when the speech changes: re-run `sync.mjs` and re-render. Sizes and
timing never live in the film as hard-coded seconds when a cue exists.

## core.js API (`window.C`)

| | |
|---|---|
| `C.W, C.H, C.FMT, C.FPS, C.DUR` | frame size from `?fmt=`; `C.pick(wide, square, tall)` returns a per-format value (4x5 uses `square`) |
| `C.at(when)` | any when -> seconds. Throws on an unknown name |
| `C.sp(t, when, preset)` | 0->1 spring released at `when`. For motion with no sound |
| `C.spHit(t, when, preset)` | same, led so it READS on the cue (see below). Use it for anything tied to a word or sound |
| `C.trk(t, [[when, v, preset?], ...])`, `C.trkObj` | a value with several targets; a retarget keeps the velocity (no restart) |
| `C.win(t, a, b)` | 1 inside [a, b) with spring edges |
| `C.seg(t, a, b)` + `C.ease.*` | linear progress. Only for typing, scrolls, slow pushes |
| `Motion.indicator(t, stops)` | bar/underline between stops; the leading edge is stiffer, so it stretches and settles |
| `Motion.swapAlpha(t, tIn, tOut)` | text inside a morphing box: invisible while the box changes shape |
| `C.el(tag, attrs, parent, html)`, `C.frag(html)` | build DOM (in `build()` only) |
| `C.reg(el, base)` | register an animated element. Hidden things: `{o: 0}` |
| `C.put(el, {x, y, s, sx, sy, r, o, hide, clip, filter, css, text, html})` | this frame's props; anything unset returns to base |
| `C.inset(t, r, b, l, radius)` | clip-path for wipes and reveals |
| `C.rectOf(el)` | live rect in stage px. Only inside `after()` |
| `C.canvas(parent)` | full-frame 2D context; clear it in `run()` every frame |
| `C.hooks.before/after.push(fn)` | global per-frame work: camera, overlays |
| `C.mulberry32(seed)`, `C.noise1(seed)` | seeded randomness |
| `C.fonts = ['600 100px Display']` | awaited before frame 0; a missing face logs `[page] font ...` |
| `C.bt(n)` | beat n -> seconds on the optional music grid |

`spHit` leads its cue by the larger of 3 frames and the time the spring needs to cover half its travel, because a
masked word is not visible for the first part of its rise. The audio stays on the cue; the picture arrives
slightly early so the eye reads the two as simultaneous.

### Scenes

```js
scene({
  name: 's02', from: 's02.start', to: 's03.start',   // whens; name = storyboard id so `render.sh motion <p> 02` finds it
  pre: 0, post: 0,                                     // overlap in seconds for wipes; cut defaults to pre === 0
  build(root, S) { /* DOM, once; store on S */ },
  run(t, S)      { /* put() everything you animate, every frame */ },
  after(t, S)    { /* things that follow live layout (rectOf) */ },
});
C.start();   // last line of film.js
```

A scene's root is visible on `[from - pre, to + post)`. `window.CUTS` (scene starts with no pre-roll) tells the
renderer where motion-blur sub-frames must not straddle.

### Type (`window.TYPE`)

```js
S.h = TYPE.line(root, 'Halve the search.', { x: 140, y: 330, size: C.pick(210, 150, 120), accent: [2] });
TYPE.rise(t, S.h, [-0.3, 'hook_w2', 'hook_w3'], 'next_in', { preset: 'heavy', exit: 0.16 });
TYPE.type(t, S.field, 'binary_search(xs, 56)', 'typing', 'typed', S.caret);
```

`rise` takes a when per word, so a title can land on the words as they are spoken. Release word 0 at a negative
time (`-0.3`) so frame 0 already reads.

## Patterns

- **Hook on frame 0.** Frame 0 is never empty; the first word is released before t = 0.
- **Algorithm stepping.** One `STEPS` array (when, state, caption). Pointers use `C.trk` over the step times, so a
  step that arrives mid-glide keeps the pointer's velocity. See `film/film.js` (the starter).
- **Sequential swaps.** One caption per step; `rise(t, L, in, nextIn - 0.05)` so the outgoing caption is gone
  before the next lands. No double exposure.
- **Receding, not vanishing.** Content the explanation has moved past dims to ~0.3 and stays, so the learner
  can still see the whole structure.
- **Holds keep moving.** A micro push (`s: 1 + 0.03 * C.seg(t, a, b)`) on any hold.
- **Re-block per format.** `C.pick` for numbers, `C.H > C.W` for structure: the starter lays 8 cells in one row
  in 16x9 and two rows of 4 in 9x16. Never letterbox 16:9 into a tall frame.
- **Camera multipliers compound.** If one scene zooms, divide it out downstream.
- **CSS 3D creates composited layers.** Run `--verify`; if it fails, fake the depth in 2D (skew + scale + shadow).

## Fonts and look

`film/index.html` holds the tokens: `--bg --ink --ink-2 --accent --hi --card` and the three font stacks. With no
font files the system stack is used, which is fine for drafts. For a shipped look, add `.woff2` files under
`assets/fonts/`, uncomment the `@font-face` rules and list the faces in `C.fonts`.

## Verifying determinism

`render.mjs --verify --all` is the gate: every probe must be pixel-identical when painted cold and after seeking
elsewhere. A failure means state leaks between frames (a timer, a CSS transition, `will-change`, a module variable
mutated in `run()`); `motion-rules.md` lists the usual causes.

## Preview in a browser

`film/index.html?fmt=16x9&play` opens a click-to-play preview (plays `audio/mix.wav` when it exists; a missing
audio file logs one harmless 404). It is for you; renders never use it.
